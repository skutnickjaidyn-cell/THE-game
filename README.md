# THE-game

A stylish browser-playable prototype for a Street-Fighter-style 2D fighting game concept.

## What's implemented

- Sleek title screen flow.
- Character select with a 22-fighter base roster.
- Stage select with 24 options (including Training and Random).
- Detailed move-list panel per fighter including jab, 3 specials, low/high/aerial, and super.
- Intro and victory text animations/descriptions per fighter.
- Battle presentation scene with polished HUD (health + super meter bars) and animated fighter panels.

## Run locally

Because this project is pure HTML/CSS/JS, you can open `index.html` directly or use a tiny local server:

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.
